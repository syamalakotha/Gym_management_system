# Apex DML Operations & SOQL Queries

## Overview

This module focuses on understanding and implementing Apex DML (Data Manipulation Language) operations and SOQL (Salesforce Object Query Language) in Salesforce. It provides hands-on experience with performing database operations and retrieving records efficiently using Apex and SOQL.

## Topics Covered

* Apex DML Operations

  * Insert
  * Update
  * Delete
  * Upsert
  * Merge
  * Undelete
* SOQL Queries

  * SELECT
  * WHERE
  * ORDER BY
  * LIMIT

## What I Learned

* Performed CRUD operations using Apex DML statements.
* Retrieved Salesforce records using SOQL queries.
* Applied filtering, sorting, and limiting techniques in SOQL.
* Understood how Apex interacts with the Salesforce database.
* Gained practical experience in managing and querying Salesforce data.

## Technologies Used

* Salesforce
* Apex
* SOQL
* Developer Console

## Outcome

Successfully implemented Apex DML operations and executed SOQL queries to manipulate and retrieve Salesforce data, strengthening my understanding of Salesforce backend development.
