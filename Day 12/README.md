# Sprint 12 – Git, Salesforce CLI, Metadata, Sandboxes and Deployment

## 1. Git

In this sprint, we learned how Git can be used to manage and track changes made to the Salesforce project.

For our **Gym Management System**, the Salesforce project contains different components such as:

- Apex Classes
- Apex Triggers
- Lightning Web Components (LWC)
- Custom Objects
- Custom Fields
- Validation Rules
- Flows
- Reports
- Dashboards

Git helps maintain the source code and keeps track of changes made to these components.
